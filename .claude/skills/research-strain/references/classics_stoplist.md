# Classics Stop-List

Terminal nodes for lineage recursion: cultivars established and documented
enough that their contribution to effects/taste can be reasoned about
directly. Stop AT these — do not trace them further. The list is a working
set, not a canon; add a cultivar when it is (a) pre-~2018-established or
equally documented, and (b) something the user can reason from.

Pre-2018-clause examples accepted in the founding campaign: Goji OG
(Bodhi), Deep Chunk, Aspen OG, High Country Diesel, Mendocino Purps.

A documented dead-end (breeder states clone-only / mystery / undisclosed)
is an equally valid terminal — a finished answer of a different kind.
