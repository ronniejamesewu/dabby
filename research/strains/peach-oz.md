# Peach OZ

- **Grower:** undisclosed · **Processor:** In House (stated — In House-branded drop menu)
- **Type:** single cultivar (cross)
- **Cross:** OZ Kush × Peach Rings — stated (In House 8.29.26 peach drop menu)
- **Breeder:** Dying Breed Seeds — corroborated (their own catalog lists "Peach Oz(z) = OZ Kush × Peach Ringz"; In House's SKU matches it exactly, so this is almost certainly Dying Breed's release, not an In House cross; Bloom's catalog already uses Peach OZ as a breeding parent in three cultivars)
